#### 6.11.7 リダイレクト

#### 6.11.9 サイト設定とURL

日本語と英語のサイトの設定（6.6.8）で、投稿のURLの規則を、WordPressのパーマリンク設定の「日付と投稿名」と同じにしたもの。設定の文書とスキーマのファイルの2つで示す。設定の文書は、キーと言語ごとの値を、書き出しと同じ順（6.6.8）に並べ、読みやすいように改行と空白を入れたもの。日本語の `frontPage` は固定ページ「ホーム」、`postsPage` は固定ページ「お知らせ」（スラッグは `news`）。`prefixDefaultLanguage`・`postsPerPage`・`authorUrl` は省いているので、既定の言語の日本語には言語のパスを付けず、一覧の1ページの件数は10、著者ページの規則は `/author/{slug}/` になる。英語には `frontPage` が無いので、英語のトップページには、最新の投稿の一覧を出力する。

設定の文書：

```json
{
  "schemaVersion": 1,
  "name": { "en": "Example Inc.", "ja": "株式会社〇〇" },
  "tagline": { "ja": "Webサイトの企画と制作" },
  "url": "https://example.com",
  "timeZone": "Asia/Tokyo",
  "logo": "med_01JBG3N6V3X6Z9C2E5G8J1K4M7",
  "icon": "med_01JBG3N6W4Y7B0D3F6H9K2M5P8",
  "languages": ["ja", "en"],
  "defaultLanguage": "ja",
  "frontPage": { "ja": "ent_01JBG3N6S1V4X7Z0C3E6G9J2K5" },
  "postsPage": { "ja": "ent_01JBG3N6T2W5Y8B1D4F7H0K3M6" },
  "seo": {
    "titleFormat": { "en": "{title} | {siteName}", "ja": "{title}｜{siteName}" },
    "ogImage": { "ja": "med_01JBG3N6X5Z8C1E4G7J0K3N6Q9" }
  }
}
```

スキーマのファイルは、6.4.4の例のファイルの `types` の最初に、投稿の規則を足したもの：

```yaml
# site/schema.yaml の一部
types:
  post:
    url: /{yyyy}/{mm}/{dd}/{slug}/   # 「日付と投稿名」。既定の規則と同じ
```

投稿の状態：

```json
{
  "schemaVersion": 1,
  "id": "ent_01JB8Y6T2WT6X9C3E6G9J2K5M8",
  "number": 123,
  "type": "post",
  "language": "ja",
  "translationGroup": "tg_01JBG3N6Q9S2V5X8Z1B4D7F0H3",
  "status": "published",
  "publishedRevision": "rev_01JBG3N6R0T3W6Y9C2E5G8J1K4",
  "createdAt": "2026-10-25T18:00:00+09:00",
  "createdBy": "usr_01JB8T7H4MA2C5E8G1J4K7N3P6"
}
```

公開中のリビジョン：

```json
{
  "schemaVersion": 1,
  "title": "新サービスを始めました",
  "slug": "新サービス",
  "date": "2026-10-26T00:30:00+09:00",
  "terms": { "category": ["trm_01JBA4C7F3H6K9N2Q5S8V1X4Z7"], "tag": ["trm_01JBA4C7G4J7M1P4R7T1W4Y7B1"] },
  "body": [
    {
      "type": "paragraph",
      "id": "b_3r8w1n6t",
      "content": [{ "type": "text", "text": "Webサイトの更新と運用をお手伝いするサービスです。" }]
```

`date` は日本時間の10月26日0時30分で、UTCでは25日（15時30分）だが、URLの日付は `date` に書いた時差で数える（6.6.8）ので、26日になる。`terms` は、6.11.3のカテゴリー「プレスリリース」（親は「お知らせ」）とタグ「イベント」。`number` の123は、WordPressの投稿IDを引き継いだもの（6.4.1）で、6.11.7のリダイレクトは、`/?p=123` からこの投稿へ転送する。
