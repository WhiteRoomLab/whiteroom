## 11. 初期実装の範囲（提案）

| 機能 | 優先度案 | 状態 |
| --- | --- | --- |
| Linuxへインストール可能なCMS本体 | 必須 | 要件・実装言語（Go）は決定、実装方式未決定 |
| SQLite + 専用Content Store | 必須 | **構成採用済み**、内部方式未決定 |
| 記事・固定ページの編集 | 必須 | 要件決定 |
| コンテンツモデル（ブロックの語彙） | 必須 | 方針決定、語彙は叩き台（6章）あり |
| 静的HTMLへのビルド・公開 | 必須 | 方式決定、トリガー等未決定 |
| ファイルベースのテーマ | 初期実装 | 方向性として合意、形式は案（5.4） |
| 管理画面と管理ユーザー機能 | 必須 | 要件決定 |
| ログイン履歴・アクティビティログ | 必須 | 要件決定 |
| お問い合わせ | 必須 | 要件決定 |
| 画像・メディア管理 | 高 | 詳細未決定 |
| 下書き・プレビュー・公開ロールバック | 高 | 提案段階 |
| ブロックエディタ | 検討 | 提案段階 |
| 独自コンテンツDSL・コンパイラ | 対象外（当面） | **採用しない**ことに決定 |
| テーマ設定GUI・レイアウト編集 | 将来拡張 | 方向性として合意 |
| 独自データストアエンジンの全面実装 | 研究候補 | 未決定 |
