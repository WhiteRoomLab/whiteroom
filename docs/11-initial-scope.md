## 11. 初期実装の範囲（提案）

| 機能 | 優先度案 | 状態 |
| --- | --- | --- |
| Linuxへインストール可能なCMS本体 | 必須 | 要件・実装言語（Go）は決定。コマンドは9.4（名前とサブコマンドの形は決定済み。9.1） |
| 専用Content Store（自作の保存の層） | 必須 | **構成採用済み**（決定済み。3.1）。作ったものは3.4の初め・4.4の初め |
| 記事・固定ページの編集 | 必須 | 要件決定 |
| コンテンツモデル（ブロックの語彙） | 必須 | 方針決定。語彙・検証・描画は6章の案で作った（一部は決定済み。6.1） |
| 静的HTMLへのビルド・公開 | 必須 | 方式決定。ビルドは4.3、公開用の内蔵サーバーは9.5（リリースの切り替えなどは決定済み。4.1）。トリガー（保存と公開の分け方）は、仮に決めた（4.4。決定済みにするかは12章の論点4） |
| ファイルベースのテーマ | 初期実装 | 方向性として合意。形式は5.4の案で作った（設定ファイルとテンプレートの名前などは決定済み。5.1） |
| 管理画面と管理ユーザー機能 | 必須 | 要件決定。作ったものは7.3の初め・9.6の初め。管理のAPI（#48）と、その後の段階で作る管理画面は、まだ無い |
| ログイン履歴・アクティビティログ | 必須 | 要件決定 |
| お問い合わせ | 必須 | 要件決定。フォームの定義と描画は6.6.5の案、送信を受け付ける処理は8章（6.12の86） |
| 画像・メディア管理 | 高 | 一部は決定済み（形式を中身から決めること、画像の原本を公開しないことなど。6.1・3.1）。ほかは6.6.2の案。メディアの追加・差し替え・保存・削除の操作は6.6.2・6.7。HTTPのアップロードと管理画面は、まだ無い |
| 下書き・プレビュー・公開ロールバック | 高 | 提案段階。エントリーの状態（予約を含む）は6.4.1、リリースの切り替えと1つ前のリリースを残すことは4.3、予約の日時の公開と戻す操作は4.4の初め |
| WordPressからの取り込み | 高 | 提案段階。一部を作った（6.10.5）。メディア・エントリー・メニュー・フォーム・リダイレクトの変換と、コマンドは、まだ無い |
| ブロックエディタ | 検討 | 提案段階 |
| 独自コンテンツDSL・コンパイラ | 対象外（当面） | **採用しない**ことに決定 |
| テーマ設定GUI・レイアウト編集 | 将来拡張 | 方向性として合意 |
| 独自データストアエンジン | 必須 | 保存の層を、自作のエンジン（3.5）に替えた（決定済み。3.1）。本番で使う前に要るものは6.12の129〜131 |
